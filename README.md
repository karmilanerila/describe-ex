# Describe Your Ex in One Word

A program that sums up an ex in exactly one word: **unsubscribe**.

The ex as an unwanted subscription — a newsletter you never signed up
for, that kept arriving, that you finally opted out of. The joke lands
at a glance, the twist is inbox admin instead of a plain insult, and
anyone who has ever hit unsubscribe on something that would not stop
coming recognises it at once.

## How it works

`main.py` writes the single word `unsubscribe` to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no
trailing newline and nothing else — exactly one word, 11 characters,
inside the 1–111 character gate. Standard library only.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
